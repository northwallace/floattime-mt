      GET api/v2/telemetrystations/telemetrystation

      Returns telemetry stations and their most recent parameter reading
      NOTICE - Changed: Added 2 new date fields to data (can also search on them). Can now search by historic status and third party status

      NameDescriptionType
      abbrev

      Station Abbreviation

      		 string
      contrArea

      Contributing Area

      		 decimal number
      county

      County where the well is located

      		 string
      dataSource

      Full data source description

      		 string
      dataSourceAbbrev

      Primary source/provider of well measurement data

      		 string
      division

      DWR Water Division

      		 integer
      drainArea

      Drainage Area

      		 decimal number
      flagA

      Station status (eg Ice Affected)

      		 string
      flagB

      Data publish status (eg Raw, Provisional, Published)

      		 string
      gnisId

      Water source - geographic name information system ID

      		 string
      huc10

      HUC 10

      		 string
      latitude

      Latitude value in decimal degrees

      		 decimal number
      locationAccuracy

      Accuracy of location coordinates

      		 string
      longitude

      Longitude (decimal degrees)

      		 decimal number
      measDateTime

      Measurement Date/Time of last recorded parameter

      		 date
      measValue

      Last recorded reading of meas_value parameter

      		 decimal number
      modified

      Last date time that this record was modified in the DWR database

      		 date
      moreInformation

      Hyperlink to additional details

      		 string
      parameter

      Parameter that last recorded meas_value is reporting

      		 string
      stage

      Last recorded stage (feet) associated with measurement parameter

      		 decimal number
      stationName

      Station Name

      		 string
      stationPorEnd

      End of period of record for this station

      		 date
      stationPorStart

      Beginning of period of record for this station

      		 date
      stationStatus

      Station Status

      		 string
      stationType

      Station Type

      		 string
      streamMile

      Distance in miles to the confluence with the next downstream water source (or distance to state line)

      		 decimal number
      structureType

      Type of structure

      		 string
      thirdParty

      Is data from third party?

      		 boolean
      units

      Units of measure

      		 string
      usgsStationId

      USGS Station ID

      		 string
      utmX

      The x (Easting) component of the Universal Transverse Mercator system. (Zone 13, NAD83 datum)

      		 decimal number
      utmY

      The y (Northing) component of the Universal Transverse Mercator system. (Zone 13, NAD83 datum)

      		 decimal number
      waterDistrict

      DWR Water District

      		 integer
      waterSource

      Name of the water source as specified in the court case

      		 string
      wdid

      DWR unique structure identifier

      		 string
